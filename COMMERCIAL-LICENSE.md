# Commercial licensing

Vey is AGPL-3.0-only. That license already permits commercial use, provided the
AGPL's conditions are met, including offering the corresponding source to users
of a modified version served over a network.

A separate commercial license is available for uses the AGPL does not allow:
distributing a modified Vey without source, shipping Vey inside a closed
product, or an OEM arrangement. It is granted per agreement, not by this
repository.

To ask for one, open an issue titled "commercial license" at
<https://github.com/fazin-ahamed/vey/issues> or contact the address in
[CITATION.cff](CITATION.cff). The terms are negotiated; nothing in this file is
an offer.
