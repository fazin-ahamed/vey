# Support

## Where to ask

| Topic | Where |
|---|---|
| Bug reports | [GitHub Issues](https://github.com/fazin-ahamed/vey/issues) |
| Feature requests | [GitHub Issues](https://github.com/fazin-ahamed/vey/issues) (label: `enhancement`) |
| Usage questions | [GitHub Discussions](https://github.com/fazin-ahamed/vey/discussions) |
| Security vulnerabilities | [SECURITY.md](SECURITY.md), private reporting only |
| Benchmark disagreements | [GitHub Issues](https://github.com/fazin-ahamed/vey/issues) (label: `benchmark`) |

Please do not report security-sensitive problems in a public issue. See
[SECURITY.md](SECURITY.md) for the private route.

## Before opening an issue

1. Check the [Limitations](docs/LIMITATIONS.md) page. Some behavior that looks
   like a bug is a documented limitation (for example, OOD recall at a tight
   false-abstain budget, or conservative tool completion).
2. Check [Discussions](https://github.com/fazin-ahamed/vey/discussions) for an
   existing thread.
3. Include your Vey version, Python version, operating system, and the exact
   command that reproduces the problem.

## Benchmark reports

Benchmark disputes are welcome, but a number without a reproduction does not
count. See [CONTRIBUTING.md](CONTRIBUTING.md) for what evidence is required.
